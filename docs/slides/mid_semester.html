      The problem

      Every grade has to become evidence for the program outcomes

      Assessments are graded in every course.

      Learning outcomes of a course are weighted averages of its assessments.

      Program outcomes, eleven for the department, are weighted averages of learning outcomes from every course.

      The department needs this for every student, every course and every term, and has to show where each number comes from.

      3 Data model: schema design

      3NF where we write, snowflake where we read

      Write side

      Normalized tables for grade entry.

      Unique keys stop double grades.

      Scores are NUMERIC, never FLOAT.

      A course or term with data cannot be deleted.

      Read side

      Fact table: Grade, one row per student and assessment.

      Dimensions: student, assessment, offering, term, course.

      The weights are bridges between dimensions, so it is a snowflake, not a star.

      Synthetic data and table size Sprint 1, Yaren Sargın

      def visible_grades(user):
    role = role_of(user)
    qs = Grade.objects.all()
    if role == HEAD:
        return qs
    if role == INSTRUCTOR:
        return qs.filter(enrollment__offering__instructors=user)
    if role == STUDENT:
        return qs.filter(enrollment__student=user)
    return qs.none()
