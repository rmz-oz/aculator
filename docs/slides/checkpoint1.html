      3NF where we write, snowflake where we read

      Write side

      Normalized tables for grade entry.

      Unique keys stop double grades.

      Scores are NUMERIC, never FLOAT.

      A course or term with data cannot be deleted.

      Read side

      Fact table: Grade, one row per student and assessment.

      Dimensions: student, assessment, offering, term, course.

      The weights are bridges between dimensions, so it is a snowflake, not a star.

      def visible_grades(user):
    role = role_of(user)
    qs = Grade.objects.all()
    if role == HEAD:
        return qs
    if role == INSTRUCTOR:
        return qs.filter(enrollment__offering__instructors=user)
    if role == STUDENT:
        return qs.filter(enrollment__student=user)
    return qs.none()
