# Screen sketches

Rough sketches for what each role sees, issue [#7](https://github.com/rmz-oz/aculator/issues/7). Paper photos are
fine too; these three are a digital stand-in so we have something to show at the sprint review even if nobody
photographs paper in time.

- `student-po-profile.svg` — a student's own PO scores (feeds [#14](https://github.com/rmz-oz/aculator/issues/14))
- `course-report.svg` — an instructor's view of one offering's LO/PO breakdown (feeds [#11](https://github.com/rmz-oz/aculator/issues/11))
- `department-report.svg` — the head of department's view across courses (feeds [#36](https://github.com/rmz-oz/aculator/issues/36))

Open an `.svg` in a browser to see it.
